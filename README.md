# hpc-ml-reference

Interactive engineering field references (single-file HTML — open or deploy anywhere).

| File | Contents |
|---|---|
| `HPC_Engineering_Interactive_Reference.html` | HPC engineering: performance, CPU/GPU architecture, precision, networking, topology, thermal, power, storage, benchmarking, glossary (76 sections, 20 calculators) |
| `ML_DL_Interactive_Reference.html` | ML/DL metrics & losses: math foundations, classification, ranking, calibration, detection, segmentation, losses, NLP, remote sensing, evaluation protocol (47 sections, 12 calculators) |
| `index.html` | Landing page linking both references |

Both pages include a **Print full reference** button that renders every section into a print-friendly multi-page document.
